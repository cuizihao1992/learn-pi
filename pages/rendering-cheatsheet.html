从数据到像素

OpenLayers 标准 VectorLayer:
Feature -> CanvasBuilderGroup -> Executor -> context.stroke()

MapLibre line layer:
Style -> WorkerTile -> LineBucket -> Painter -> gl.drawElements(TRIANGLES)

Cesium:
Entity/Primitive -> update -> DrawCommand -> commandList -> WebGL

快速选择

  • 复杂投影、WMS/WFS、业务要素编辑：先看 OpenLayers。
  • 自托管矢量底图、标签排版、统一 Style：先看 MapLibre。
  • 三维地球、地形、3D Tiles、卫星和全球高度：先看 Cesium。
  • 二维运营与三维场景都需要：用共享业务 ID 和状态连接两个视图，不必强迫一个 renderer 承担全部任务。

Mapbox 放在哪里

MapLibre 起源于 Mapbox GL JS 1.13 的开源分支，但两者已经独立演进。学习开源渲染源码、可自托管基础能力时进入 MapLibre 模块；研究 Mapbox 产品 API 和服务生态时进入 Mapbox 模块。不要默认当前新 API 可以互换。
