Agent 与大模型

概念一句话入口
toolCall模型提出“我要调用哪个工具和参数”。工具调用
toolResult运行时执行工具后，把真实结果回填给模型。Mini Agent
OpenAI-compatible让不同模型伪装成同一种 API 协议。模型接口
Embedding把文本、图片、代码等对象变成可比较的语义向量。Embedding 与多模态
RAG先检索证据，再让模型回答。RAG 工程
多模态模型把图像、音频、视频等模态接入语言模型的理解和生成能力。Embedding 与多模态
Prompt Cache复用稳定 prompt 前缀的预填充计算，减少重复推理成本。角色优先级与缓存
KV Cache推理时保存历史 token 的 Key/Value，避免每生成一个 token 都重算历史上下文。角色优先级与缓存
运行日志Agent 本轮可见的 system、developer、user、assistant、tool、RAG 证据和文件片段。角色优先级与缓存
自回归生成用已经生成的前文预测下一个 token，因此 token 与 token 之间天然串行。投机解码原理
Speculative Decoding小模型先草拟多个 token，大模型一次验证并接受最长有效前缀。投机解码原理
DFlash用轻量 block diffusion / masked parallel prediction drafter 一次生成一块草稿 token。投机解码原理
TileRT面向低延迟推理的 runtime，通过 persistent kernel、tile pipeline 等减少 GPU 执行缝隙。MiMo UltraSpeed 案例
GPU 调度碎片kernel 启动、同步、通信和数据搬运之间的微小等待，会在高速推理中放大成瓶颈。MiMo UltraSpeed 案例
