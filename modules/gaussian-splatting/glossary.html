Gaussian Splatting 核心术语表

术语准确含义不要误解为
Gaussian mean / μ三维高斯的中心位置。完整几何形状。
Covariance / Σ描述影响范围、各轴尺度及方向的对称矩阵。训练数据的统计方差报告。
Scale + rotation构造合法三维协方差的参数化方式。屏幕 CSS transform。
Splat一个三维高斯投影到屏幕后形成的二维连续贡献。固定大小的不透明圆点。
Conic二维协方差逆矩阵的紧凑表示，用于计算像素指数权重。包围圆半径。
Spherical harmonics / SH用一组基函数表达随观察方向变化的颜色。决定高斯空间形状的参数。
Opacity高斯在中心处的最大 alpha 系数，通常由 sigmoid 激活。最终像素 alpha；后者还乘高斯权重。
Transmittance / T光线在处理当前高斯之前仍未被遮挡的比例。单个高斯的 opacity。
Tile binning把高斯组织到它覆盖的屏幕瓦片中，缩小逐像素候选集合。地理地图的网络瓦片。
Densification依据屏幕梯度和尺度 clone 或 split 高斯，增加表达能力。单纯把所有点等比例复制。
Pruning删除低 opacity、过大或无效的高斯。图像压缩。
Differentiable rasterizer既计算图像，也能把损失梯度传回 Gaussian 参数的光栅器。由神经网络替代全部渲染过程。

最容易混淆的三组关系

  • `Σ3D` 描述空间椭球，`Σ2D` 描述当前相机下的屏幕椭圆，`Σ2D⁻¹` 才是像素循环使用的 conic。
  • radius 是快速包围范围，weight 是某个像素的真实连续贡献，alpha 是 weight 再乘 opacity。
  • 训练和实时展示都要前向渲染，但训练还要保存中间量并执行 backward。
