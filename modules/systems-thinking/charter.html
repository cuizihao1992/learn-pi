Module Charter

系统思维内容怎么写

系统思维模块不是抽象哲学，而是一个分析工具箱。每篇内容都要帮读者从“这个事好复杂”走到“我能画出它的变量、反馈和干预点”。

一、每篇内容的固定骨架

  1. 定义系统边界：讨论的是公司、城市、市场、学习过程，还是 Agent 运行时？
  2. 列关键变量：哪些变量会相互影响？
  3. 区分存量与流量：什么在积累，什么在流入流出？
  4. 画反馈环：哪些关系会自我增强，哪些关系会自我抑制？
  5. 找延迟：动作和结果之间隔多久？
  6. 找杠杆点：改参数、改规则、改信息流、改目标，哪个更有效？

三、和其他模块的关系

  • Agent 模块：工具调用、记忆、RAG 和评估都是反馈系统。
  • 经济金融模块：信用、通胀、利率、房租和资产价格都是动态系统。
  • 历史社会模块：战争升级、联盟锁链和制度失灵都是反馈环失控。
  • 认知学习模块：学习、遗忘、复习和输出也是存量流量系统。
