Feedback Loops

看懂反馈环，很多复杂现象就不再神秘

反馈环是系统行为的发动机。一个变量影响另一个变量，后者又反过来影响前者，这就形成了反馈。增强反馈会放大变化，平衡反馈会抵消变化。

两类反馈

类型作用例子
增强反馈越多越多，越少越少，推动增长或崩溃。用户越多 -> 内容越多 -> 吸引更多用户。
平衡反馈偏离目标后产生纠偏力量，让系统趋向稳定。房价太高 -> 需求下降 -> 价格压力下降。

为什么反馈会让系统反直觉

  • 短期反馈和长期反馈可能方向相反。
  • 一个动作可能同时触发多个环路。
  • 延迟会让人误判因果，把今天的结果归因给昨天的动作。
  • 增强反馈一旦跨过阈值，变化会突然变快。

例子：Agent 工具调用循环

模型不确定
  -> 调用更多工具
  -> 上下文变长、噪声增加
  -> 模型更难判断
  -> 继续调用工具

这就是一个可能的增强反馈。解决办法不是简单禁止工具，而是加入平衡反馈：最大调用次数、工具结果摘要、任务完成判定、置信度阈值。
