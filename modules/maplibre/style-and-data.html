Style And Data

为什么 Source 有数据，Layer 仍可能没有像素

MapLibre 把“数据在哪里”和“数据怎样画”明确分离。一份 source 可以被多个 style layer 重用，而每个 layer 还会通过 source-layer、filter、zoom、layout 和 paint 再筛选一次。

一个最小 Style

{
  "version": 8,
  "sources": {
    "route": {
      "type": "geojson",
      "data": {
        "type": "FeatureCollection",
        "features": [{
          "type": "Feature",
          "properties": { "kind": "primary" },
          "geometry": {
            "type": "LineString",
            "coordinates": [[116.32, 39.90], [116.46, 39.94]]
          }
        }]
      }
    }
  },
  "layers": [{
    "id": "route-line",
    "type": "line",
    "source": "route",
    "filter": ["==", ["get", "kind"], "primary"],
    "paint": {
      "line-color": "#087f72",
      "line-width": ["interpolate", ["linear"], ["zoom"], 8, 2, 14, 8]
    }
  }]
}

五个容易混淆的对象

对象问题例子
Source数据从哪里来、按什么类型加载？`route` GeoJSON 或一个 vector tile endpoint。
Source Layer一个矢量瓦片内部选择哪张逻辑表？PBF 中的 `road`、`building`。GeoJSON source 不填它。
Style Layer选中哪些要素，以哪种渲染类型画？`route-line`，类型为 `line`。
Layout几何和放置怎样组织？`line-cap`、`symbol-placement`、`visibility`。
Paint最终外观是什么？`line-color`、`line-width`、`fill-opacity`。

Source Layer 为什么不是 Style Layer

一个 vector tile 文件可以同时包含道路、建筑、水系等命名图层。`source-layer` 先从 PBF 内选中一组要素；Style Layer 再决定用 `line`、`fill` 或 `symbol` 怎样展示它。相同的 `road` source layer 可以被道路底色、描边和标签三个 style layer 重复使用。

vector source "city"
  -> PBF source-layer "road"
     -> style layer "road-casing" 画粗描边
     -> style layer "road-fill"   画内部颜色
     -> style layer "road-label"  画道路名称

Expression 在哪里执行

表达式不是全部在每帧逐要素解释。与 feature 数据相关、且会影响几何布局的属性通常在 worker layout 阶段参与 bucket 生成；数据驱动 paint 属性可由 `ProgramConfiguration` 准备 paint vertex array，常量属性则可以作为 uniform。官方架构文档明确把 `#pragma maplibre` 展开和 paint attribute/uniform 选择归入 ProgramConfiguration（ARCHITECTURE.md）。

变化可能触发成本直觉
相机移动可见 tile 更新、uniform 更新、重绘通常不重建所有静态 bucket。
常量 paint 改变样式重算和重绘可能只改 uniform，通常较轻。
数据驱动 paint 改变paint attribute 更新与受影响 feature 和 buffer 相关。
layout / filter 改变tile 重新 parse/layout可能重建 bucket，通常更重。
GeoJSON `setData`worker 重新切片和 parse大数据高频更新容易卡顿。

Style 加载发生了什么

`Style.loadJSON()` 在下一帧调用 `_load()`：先校验 style，再创建 sources、加载 sprite、设置 glyph URL、创建 layers、projection、sky 和 terrain，最后触发 style load 事件（Style._load）。因此“页面有 canvas”只说明 Map 初始化了，不代表 style、source、sprite、glyph 和 tile 都已完成。
