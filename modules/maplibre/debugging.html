Debugging

MapLibre 地图空白或卡顿，从哪一层查

遵循最短证据链：先证明 canvas 能画，再证明 Style 生效、Source 有数据、Layer 选中要素、worker 产出 bucket，最后才查 shader 和 GPU。

六层排查表

层检查常见错误
容器 / WebGL元素尺寸、canvas、console、`webglcontextlost`父容器高度为 0、GPU context 创建失败。
Style`style.load`、style 校验错误、background layerJSON 版本、source/layer schema、URL 404。
Source / 网络Network、CORS、tile URL、响应格式token、跨域、MIME、TMS/XYZ y 方向、PBF 损坏。
Worker / layoutworker URL、CSP、source-layer、glyph/spriteESM worker 文件不完整、严格 CSP 禁止 blob worker。
Style Layervisibility、filter、minzoom/maxzoom、opacity数据存在但没有要素通过当前规则。
GPU / passbucket buffer、shader 编译、custom layer 状态自定义 WebGL 污染状态、context 丢失、深度/混合错误。

先建立无网络基线

const style = {
  version: 8,
  sources: {},
  layers: [{
    id: 'background',
    type: 'background',
    paint: {'background-color': '#dfe8ea'}
  }]
};

若 background 都看不到，问题在容器、CSS、Map 初始化或 WebGL，不要先调 tile server。若 background 正常，再加一个内联 GeoJSON source 和 circle/line layer，把服务端变量排除。

事件探针

map.on('error', e => console.error(e.error));
map.on('styledata', e => console.log('styledata', e));
map.on('sourcedata', e => console.log('sourcedata', e.sourceId));
map.on('webglcontextlost', e => console.warn('context lost', e));
map.on('idle', () => console.log('idle'));

不要只监听 `load`。字体、sprite、后续 tile 和数据更新都可能在不同时间失败。

MapLibre 6 的 worker 部署陷阱

官方 6.9.0 文档说明 v6 只发布 ESM。Vite 应使用 `?worker&url` 让 worker 管线生成自包含 chunk；只用 `?url` 可能遗漏相邻的 `maplibre-gl-shared.mjs`。严格 CSP 不允许 `blob:` worker 时，应把 worker 放到同源地址并显式调用 `setWorkerUrl()`（官方 ESM 安装说明）。

import {Map, setWorkerUrl} from 'maplibre-gl';
import workerUrl from 'maplibre-gl/dist/maplibre-gl-worker.mjs?worker&url';

setWorkerUrl(workerUrl);

性能问题按成本来源拆

现象可能瓶颈优先验证
首次加载慢tile/glyph/sprite 网络，PBF 解析资源瀑布、压缩、缓存、worker 时间。
拖动掉帧layer/vertex 过多、过绘制、symbol placement减少 layer 与可见数据，比较是否恢复。
更新数据卡顿大 GeoJSON 高频 `setData`降低更新频率、拆动态 source、改 vector tile。
显存持续增长过大 tile cache、自定义 layer 资源未释放调用 `map.remove()`，检查 texture/buffer 生命周期。
点击查询慢查询区域过大、layers 未限制、返回要素太多限制点/小框和目标 layer。

生产检查清单

  • 固定 MapLibre 版本并记录 Style Spec 兼容范围。
  • 为 style、sprite、glyph、tile 和 worker 设置正确 CORS、缓存与内容类型。
  • 区分渲染库许可和数据供应商许可。
  • 监听 error 与 context loss，并给关键地图提供降级状态。
  • 销毁页面时调用 `map.remove()`，释放事件、worker 和 WebGL 资源。
  • 用真实低端移动设备测试 layer 数、vertex 数和内存，不只看开发机。
