MapLibre GL JS：把地图样式编译成 GPU 绘制

MapLibre GL JS 是社区维护、BSD-3-Clause 许可的浏览器地图渲染引擎。它读取 Style 文档和地理数据，在 Web Worker 中把要素布局成 GPU 可用的 bucket，再由 WebGL 按图层和 render pass 绘制。当前课程以 6.9.0 与源码提交 `ae328866` 为基准。

先回答：它和 Mapbox 是什么关系

MapLibre GL JS 起源于 Mapbox GL JS 1.13 的开源分支，背景是 Mapbox 在 2020 年 12 月转向非开源许可。最初的 MapLibre 1.x 追求兼容开源版 Mapbox API，但此后已经持续独立演进。今天应把它当作自己的社区项目和技术栈，而不是假设所有新 Mapbox GL JS API 都能直接替换（官方 README）。

MapLibre 是渲染库，不是底图数据。你仍需要 Style JSON、矢量/栅格瓦片、字体 glyph、sprite 或自己的 GeoJSON 服务。代码开源不等于所有地图数据免费，也不等于可以忽略数据许可。

它解决什么问题

声明地图外观

用 Style Specification 描述 sources、layers、paint、layout、filter、sprite、glyphs、projection 和 terrain。

高效处理瓦片

只调度当前视口需要的 tile，并在 worker 中解析 PBF、筛选要素、生成渲染缓冲。

GPU 批量绘制

固定 layer 类型映射到专门 shader 和 draw 路径，线、面、符号都按 bucket 批量提交。

地图交互

相机、事件、控件和 FeatureIndex 让业务代码能缩放、旋转、拾取和更新 feature-state。

不要再只记 `new Map()`

Map + Style JSON
  -> Style 创建 Source 与 StyleLayer
  -> Transform / camera 确定可见 tile
  -> WorkerTile 解析与 layout
  -> Bucket 生成顶点、索引和样式属性
  -> 主线程上传 GPU buffer
  -> Painter 按 pass 和 layer 顺序调度
  -> Program.draw() -> gl.drawElements()
  -> 像素

当前能力边界

  • 核心强项：矢量瓦片、样式表达式、标签避让、平滑交互和 GPU 地图渲染。
  • 不再只是平面：当前版本支持 globe projection、terrain、fill extrusion 和 custom 3D layer。
  • 仍不同于 Cesium：Cesium 把椭球地球、全球地形、3D Tiles 和三维场景调度作为一等核心；MapLibre 的核心数据组织仍围绕地图 style layer 与 tile。
  • 仍不同于 OpenLayers：OpenLayers 更强调多投影、OGC 服务、Feature/Geometry 对象和可选择的 Canvas/WebGL renderer；MapLibre 更强调统一 Style Spec 和 GPU-first 瓦片管线。

  1. 样式与数据：先分清 Style、Source、Source Layer、Style Layer、layout 和 paint。
