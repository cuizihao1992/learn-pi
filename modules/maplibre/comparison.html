Comparison

MapLibre、OpenLayers、Cesium 应该怎么选

不要先问“谁性能最好”。先问你要表达的是样式化地图、通用 GIS 数据，还是全球三维场景。三者都能显示地理信息，也都能接入 WebGL，但它们优化的中心完全不同。

先记住三句话

  • MapLibre：把 Style 和瓦片高效编译成 GPU 地图，强项是矢量底图、标签和一致的视觉系统。
  • OpenLayers：把多来源、多格式、多投影的 GIS 数据组织成可交互二维地图，强项是兼容与业务编辑。
  • Cesium：把椭球地球、地形、影像、3D Tiles 和时间动态对象组织成全球三维场景，强项是尺度与三维空间。

同一条线，底层路径有什么不同

MapLibre:
Style line layer -> WorkerTile -> LineBucket 三角形
-> Painter -> Program.draw -> gl.drawElements(TRIANGLES)

OpenLayers 标准 VectorLayer:
Feature -> VectorSource -> CanvasVectorLayerRenderer
-> CanvasBuilderGroup 指令 -> Executor -> context.stroke()

Cesium Point / Primitive:
Entity/Geometry -> Visualizer/Primitive.update
-> DrawCommand -> commandList -> WebGL draw

MapLibre 先把地图语义编译成 tile bucket；OpenLayers 保留更直接的 Feature 与 renderer 关系；Cesium 则把三维对象变成可排序的 DrawCommand。三条路径的“中间表示”不同，所以性能调优的抓手也不同。

MapLibre 有 globe，为什么还要 Cesium

“能显示球体”不等于“拥有相同三维场景模型”。MapLibre 当前 globe projection 能把地图瓦片投影到球面，并支持 terrain、挤出和 custom layer（官方 globe 示例）；Cesium 的 Globe、TerrainProvider 和 Cesium3DTileset 则围绕全球高程、视锥/地平线裁剪、屏幕空间误差和海量三维内容调度设计（Cesium terrain、Cesium3DTileset）。

若需求只是“把矢量地图从平面切到球面”，MapLibre 很合适；若需求是“在全球尺度管理地形、模型、点云、建筑和时间动态对象”，Cesium 的抽象更匹配。

MapLibre 与 OpenLayers 的关键分界

OpenLayers 官方强调任意来源的 tile、vector、marker，以及 GeoJSON、KML、GML、Mapbox vector tiles、OGC 服务和 Canvas/WebGL（OpenLayers 官方概览）。这让它像 GIS 应用框架。MapLibre 则要求你把视觉意图放进 Style Layer，并围绕 worker bucket 和 WebGL 批量渲染，像地图渲染引擎。

  • 需要频繁直接创建、修改、选择和编辑业务 Feature：OpenLayers 往往更自然。
  • 需要让同一份 MVT 在多个 zoom 上形成完整制图风格和标签体系：MapLibre 往往更自然。
  • 两者都能做很多相同页面，选择应看主要工作流，而不是列功能勾选表。

组合架构怎么用

组合适合注意
MapLibre 2D + Cesium 3D同一业务提供运营平面视图与三维场景视图。共享业务状态与 ID，不要强行共享 renderer。
OpenLayers 编辑端 + MapLibre 展示端后台 GIS 编辑复杂要素，前台发布品牌化矢量地图。以服务端数据和样式发布流程作为边界。
MapLibre custom layer + Three.js在地图相机中插入有限自定义三维对象。管理共享 WebGL 状态、深度和资源释放；复杂全球场景仍应重新评估 Cesium。

三类常见误判

  • “MapLibre 免费，所以地图免费”：库许可、数据许可和托管成本是三件事。
  • “MapLibre 支持 globe，所以等于 Cesium”：投影形态相似，不代表数据模型和调度能力相同。
  • “OpenLayers 用 Canvas，所以一定慢”：性能取决于 renderer、数据量、样式和更新方式；OpenLayers 也提供 WebGL 路径。
  • “Cesium 太重，所以不好”：它承担了其他两个引擎通常不承担的三维地球复杂度。

结论

选择引擎就是选择主要中间表示：选择 MapLibre 的 Style/Bucket，选择 OpenLayers 的 Feature/Layer/Source，或选择 Cesium 的 Scene/Primitive/DrawCommand。最匹配业务核心的数据模型，通常比 API 表面相似度更重要。
