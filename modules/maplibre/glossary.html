MapLibre 核心术语表

术语含义常见误解
Style描述 sources、layers、sprite、glyphs、projection 等的渲染合同。只是一组 CSS 颜色。
SourceGeoJSON、vector、raster、raster-dem、image、video、canvas 等数据入口。已经画在屏幕上的图层。
Source Layer矢量瓦片内部的命名数据层。Style Layer 的 id。
Style Layer引用 source 并定义渲染类型与规则的样式层。独立复制的一份数据。
Layout影响几何组织、符号放置或可见性的属性。网页 CSS layout。
Paint颜色、宽度、透明度等绘制属性。全部只在 CPU 上执行。
Expression由 zoom、feature 属性、feature-state 等输入计算样式值的表达式。任意 JavaScript 回调。
Tile瓦片金字塔中某个 z/x/y 的数据和渲染资源单元。必然是一张 PNG。
Bucket某 tile 中一组相容 Style Layer 的 GPU-ready 几何与样式数组。网络缓存目录。
WorkerTile在 worker 中解析 tile、筛选 feature、创建 bucket 和 FeatureIndex 的对象。负责最终 WebGL 绘制的线程。
Painter主线程上按 pass、layer、tile 组织 GPU 绘制的核心调度器。绘制每个 feature 的 Canvas API。
ProgramConfiguration连接 Style paint 属性与 shader uniform/attribute 的配置层。应用构建配置。
FeatureIndextile 内供 `queryRenderedFeatures` 候选筛选和命中测试使用的空间索引。GPU framebuffer 的颜色拾取。
Feature State不改原始数据即可按 feature id 注入的临时状态。会自动持久化回服务端。
Custom Layer共享 MapLibre WebGL context 和相机的自定义绘制接口。普通 Style Layer 的任意新 type 字符串。
