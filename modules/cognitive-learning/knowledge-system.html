Knowledge System

从收藏夹到可生长的知识库

知识库的核心不是“存得多”，而是“能找回、能连接、能复用、能输出”。本站可以按五层组织：TIL 捕捉、概念索引连接、模块页面展开、实验验证、项目输出。

五层结构

层级用途本站入口
TIL快速记录今天学到的概念、问题、案例和灵感。TIL 学习日志
概念索引把术语和模块连接起来，形成可检索的知识地图。概念索引
模块页面把一个主题拆成总览、路线、关键机制、案例和练习。全部模块
实验 Demo用最小可运行例子验证概念，避免只停留在文字理解。实验室
项目输出做成工具、文章、代码、分析报告或可讲解的课程。项目清单

每次学习后的 10 分钟整理

  1. 写一句话：今天真正学到的是什么。
  2. 列 3 个关键词：它连接哪些概念。
  3. 补 1 个例子：最好来自现实或代码。
  4. 问 1 个问题：还有哪里没懂。
  5. 决定去向：留在 TIL，还是迁移到正式模块。

知识从零散到体系的路径

信息：看到一篇文章、一个视频、一次对话
  -> TIL：记录最小条目
  -> 概念索引：建立连接
  -> 模块页：扩写为结构化解释
  -> 实验：用代码、图表或案例验证
  -> 输出：讲给别人、做成项目、形成自己的判断

最重要的原则

不要把知识库当仓库，要把它当工坊。仓库追求保存，工坊追求加工。每个页面都应该能被继续改写、重组、检索和复用。
