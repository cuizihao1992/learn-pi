Labs

一次只破坏渲染链的一层

准备一个只含一个点的 GeoJSON 和一个 circle layer。每轮只改变一个变量，记录网络、source、style layer、相机和屏幕结果。

实验 1：source id 失配

map.addSource("stations", { type: "geojson", data });
map.addLayer({ id: "station-dot", type: "circle", source: "station" });
// source 写成了 station，而实际 id 是 stations

预测报错位置，再把 source 改正确。说明 style layer 只保存数据引用，不复制 source 数据。

实验 2：交换经纬度

分别使用 `[116.4, 39.9]` 和 `[39.9, 116.4]`，固定相机在北京。两组都是合法数字，但只有一组位于预期视野。

验收：能区分“没有生成要素”和“要素生成了但在视野外”。

实验 3：混淆 source-layer

// GeoJSON source 不使用 source-layer
{ type: "circle", source: "stations" }

// Vector source 的 style layer 需要选择瓦片内部图层
{ type: "line", source: "transport", "source-layer": "road" }

解释 source id 与瓦片内部 source-layer 为什么是两级命名空间。

实验 4：让 filter 与 zoom 隐藏数据

先设置无法命中的 filter，再设置高于当前 zoom 的 `minzoom`。检查 source 是否 loaded、要素是否存在、layer 是否可见，建立固定排查顺序。

自测

source 与 layer 的根本区别是什么？

source 定义数据从哪里来；layer 选择一部分数据并规定以何种图形和顺序绘制。

为什么 layout 修改通常比 paint 修改更重？

layout 会影响要素如何参与布局和传给 GPU，可能触发异步重新布局；paint 更接近绘制阶段的外观属性。

worker 为什么不能独立完成最终绘制？

worker 适合解析和布局，但 WebGL 上下文、最终图层顺序与每帧相机状态由渲染主流程统一协调。
