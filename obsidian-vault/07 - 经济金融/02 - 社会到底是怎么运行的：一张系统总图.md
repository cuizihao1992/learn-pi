# 社会到底是怎么运行的：一张系统总图

如果你想对社会运行有更深刻的认识，不能只学“经济学”或“金融学”某一个点。要把社会看成一个多层系统：家庭提供劳动和消费，企业组织生产，政府制定规则和再分配，金融体系跨时间调配资金，城市承载人口和产业，国际体系改变边界。

## 一、六个核心部门

| 部门 | 做什么 | 拿什么收入 | 受什么约束 |
| --- | --- | --- | --- |
| 家庭 | 提供劳动、消费、储蓄、教育下一代 | 工资、经营收入、租金、利息、分红、转移支付 | 时间、技能、资产、城市、家庭结构 |
| 企业 | 组织生产、雇佣劳动、销售商品服务 | 销售收入、融资、补贴 | 成本、竞争、技术、需求、监管 |
| 政府 | 制定法律、税收、支出、公共服务、监管 | 税收、国有资产收入、债务融资 | 财政能力、政治目标、社会稳定、债务 |
| 金融体系 | 存款、贷款、支付、投资、保险、资产定价 | 利差、手续费、投资收益 | 信用风险、流动性、监管、信心 |
| 城市 | 承载土地、住房、产业、交通和公共资源 | 土地收益、税费、产业收入 | 土地稀缺、人口流动、基础设施 |
| 海外部门 | 贸易、资本流动、汇率、技术和规则外溢 | 出口收入、投资收益、外汇 | 国际规则、汇率、地缘政治、供应链 |

## 二、社会运行的主循环

```text
家庭 -> 提供劳动和消费需求
企业 -> 组织生产并支付工资、租金、利息、利润
政府 -> 提供规则、公共品和再分配
金融 -> 把储蓄、信用和风险跨时间配置
城市 -> 把人、地、产业、公共服务集中到空间里
全球 -> 通过贸易、汇率、资本、技术改变国内价格和机会
```

## 三、你看到的社会现象，通常是多层共同作用

| 现象 | 不要只看 | 要同时看 |
| --- | --- | --- |
| 一线城市房租高 | 房东贪心 | 土地稀缺、产业集聚、高收入人群、公共资源、金融信贷、政策供地 |
| 工资差异大 | 老板愿不愿意给 | 劳动生产率、岗位稀缺、行业利润、议价能力、制度保护、城市机会 |
| 物价上涨 | 商家涨价 | 需求、供给、成本、货币信用、税费、汇率、预期 |
| 年轻人压力大 | 个人不努力 | 住房、教育、产业结构、代际资产、城市资源、劳动市场 |
| 全球化冲击 | 外国竞争 | 比较优势、产业链、汇率、贸易规则、资本流动、技术标准 |

## 四、学习社会运行的正确顺序

- 先学经济学：价格、供需、激励、市场失灵。

- 再学金融学：现金流、利率、风险、信用。

- 再学财政货币：政府钱怎么来，银行如何创造信用。

- 再学城市经济：为什么机会、工资、房租和公共资源集中。

- 再学国际经济：贸易、汇率、美元体系、资本流动和全球规则。

- 最后回到历史和制度：产权、土地、税制、教育、户籍、产业政策如何长期塑造分配。

## 五、一个成熟的社会观察问题模板

```text
看到一个社会现象，按这 8 个问题拆：
1. 谁是参与者？
2. 他们分别有什么资源和约束？
3. 钱从哪里来，流向哪里？
4. 价格由什么供需关系决定？
5. 政府规则改变了什么激励？
6. 金融信用放大了什么？
7. 空间和城市位置有什么影响？
8. 全球贸易、汇率、资本和技术有没有参与？
```
