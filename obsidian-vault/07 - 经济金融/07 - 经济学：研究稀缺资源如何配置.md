# 经济学：研究稀缺资源如何配置

经济学不是“赚钱学”，而是研究人在约束下如何选择，社会如何通过价格、制度、组织和政策配置有限资源。

## 一、经济学的核心骨架

```text
稀缺性
  -> 人必须选择
  -> 选择有机会成本
  -> 人对激励作出反应
  -> 市场用价格协调供需
  -> 市场有时失灵
  -> 制度和政策尝试修正
  -> 修正本身也有成本和副作用
```

## 二、微观经济学

| 主题 | 核心问题 | 你要掌握 |
| --- | --- | --- |
| 供给与需求 | 价格和数量如何决定？ | 需求曲线、供给曲线、均衡、短缺、过剩。 |
| 弹性 | 价格变化会带来多大数量变化？ | 需求弹性、供给弹性、收入弹性、税负归宿。 |
| 消费者选择 | 人在预算约束下如何选择？ | 边际效用、预算线、替代效应、收入效应。 |
| 企业生产 | 企业如何决定产量和成本？ | 边际成本、平均成本、规模经济、利润最大化。 |
| 市场结构 | 竞争程度如何影响价格？ | 完全竞争、垄断、寡头、垄断竞争。 |
| 市场失灵 | 市场什么时候不能自动变好？ | 外部性、公共品、信息不对称、垄断。 |

## 三、宏观经济学

宏观经济学看的是总量：一个国家或地区整体的产出、收入、就业、物价、利率、货币、财政和国际收支。

- GDP： 衡量一段时间内生产出来的最终产品和服务价值。

- 通胀： 总体价格水平持续上升，不只是某个商品涨价。

- 失业： 劳动力资源未被充分使用，也反映需求和结构问题。

- 利率： 资金的价格，也是跨期选择的核心变量。

- 货币政策： 央行通过利率、流动性、预期影响经济。

- 财政政策： 政府通过税收、支出、赤字影响总需求和资源分配。

## 四、经济学的思维方式

- 看边际，而不是只看总量。

- 看激励，而不是只看愿望。

- 看约束，而不是只看目标。

- 看替代方案，而不是只看一个选择。

- 看一般均衡，而不是只看局部好处。

- 看政策副作用，而不是只看初衷。

## 五、一个例子：最低工资

最低工资不是简单的“提高收入”。经济学会问：劳动需求弹性多大？企业会不会减少招聘？低收入劳动者是否真的受益？地区和行业差异如何？有没有税收抵免、培训、转移支付等替代政策？这就是经济学的味道：不只看立场，而看机制和约束。
