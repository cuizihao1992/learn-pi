# 金融学：研究资金如何跨时间和风险配置

金融学的核心是：今天的钱和未来的钱不同，确定的钱和不确定的钱不同。金融市场、银行、保险、证券、基金、衍生品，本质上都围绕现金流、时间和风险展开。

## 一、金融学主线

```text
现金流
  -> 时间价值
  -> 折现率
  -> 资产价格
  -> 风险收益
  -> 组合分散
  -> 金融机构和市场
  -> 监管与系统性风险
```

## 二、必须掌握的基础概念

| 概念 | 一句话 | 为什么重要 |
| --- | --- | --- |
| 时间价值 | 现在的 1 元通常比未来的 1 元更值钱。 | 所有估值都要折现。 |
| 现金流 | 资产未来能带来的钱。 | 债券、股票、公司估值都看现金流。 |
| 折现率 | 把未来现金流折回今天的利率。 | 折现率越高，资产现值越低。 |
| 风险溢价 | 承担风险要求的额外收益。 | 解释为什么股票长期预期收益高于无风险资产。 |
| 流动性 | 资产能否快速低成本变现。 | 流动性差的资产需要补偿。 |
| 杠杆 | 借钱放大资产暴露。 | 放大收益，也放大亏损和爆仓风险。 |

## 三、主要资产

- 债券： 相对明确的未来现金流，核心看利率、期限、信用风险。

- 股票： 对公司未来剩余现金流的索取权，核心看盈利、增长、折现率和预期。

- 基金： 把一篮子资产打包，由管理人或规则管理。

- 衍生品： 价值来自标的资产，如期货、期权、互换，用于套保、投机或套利。

- 银行贷款： 金融机构把存款和资本转化为信用创造。

## 四、金融市场为什么存在

| 功能 | 解释 |
| --- | --- |
| 融资 | 把有资金的人和需要资金的人连接起来。 |
| 定价 | 把市场对现金流、风险和预期的判断反映到价格里。 |
| 风险转移 | 让不同风险承受能力的人交换风险。 |
| 流动性 | 让资产可以交易，降低持有成本。 |
| 信息聚合 | 价格包含很多参与者的信息和预期。 |

## 五、和投资的关系

金融学不是教你“买哪只股票”，而是教你理解：为什么估值会变，为什么利率上升会压制高久期资产，为什么高收益通常伴随高风险，为什么分散组合能降低非系统性风险，为什么流动性危机会让好资产也被抛售。
