# 量化是怎么做的：从想法到自动交易系统

量化交易不是“用 AI 自动赚钱”，而是把交易想法写成明确规则，用历史数据验证，用风控约束，用程序执行。它的核心不是代码炫技，而是研究假设、数据质量、回测真实性、实盘稳定性和风险控制。

## 一条完整链路

```text
交易假设
  -> 获取和清洗数据
  -> 生成特征和信号
  -> 回测撮合
  -> 评估收益、回撤、换手、滑点
  -> 参数稳定性和样本外测试
  -> 模拟盘 / 纸面交易
  -> 实盘下单
  -> 监控、风控、复盘、迭代
```

## 量化和主观看盘的区别

| 维度 | 主观看盘 | 量化交易 |
| --- | --- | --- |
| 决策来源 | 经验、图形、消息、临场判断 | 规则、模型、统计检验、程序执行 |
| 优点 | 能理解复杂语境，适合少量标的深度判断 | 可复现、可批量、可回测、可监控 |
| 缺点 | 容易情绪化，复盘困难 | 容易过拟合，依赖数据和工程质量 |
| 关键能力 | 市场理解和纪律 | 数据、统计、工程、风控、执行 |

## 量化系统的几个角色

### 研究层

提出假设，例如“低波动高质量股票长期超额收益更好”“突破长期平台后动量延续”。研究层要避免数据挖掘和幸存者偏差。

### 数据层

处理行情、财务、复权、成分股、停牌、分红、交易日历。数据错，后面所有漂亮结果都可能是幻觉。

### 回测层

按历史时间推进，生成信号、撮合订单、计算手续费滑点，避免偷看未来。

### 实盘层

连接券商 API、行情源、风控服务和监控告警。实盘更重稳定性，不是把回测脚本直接跑起来。

## 入门最推荐的路线

- 先学 Python、pandas、基础统计、收益率、波动率、回撤、夏普比率。

- 先做日频策略，不要一上来做高频。日频更适合理解研究、回测和风控。

- 用很简单的策略练完整流程，例如均线趋势、动量轮动、低波动组合。

- 回测必须加入手续费、滑点、调仓限制、停牌、涨跌停、交易日历。

- 先模拟盘，再小资金实盘。实盘稳定性和心理压力会暴露很多回测看不到的问题。

## 必须警惕的误区

- 过拟合： 参数调到历史最好，不代表未来最好。

- 幸存者偏差： 只用今天还活着的股票回测，会高估收益。

- 未来函数： 用了当时不可能知道的数据，例如未来财报、未来成分股。

- 忽略交易成本： 高换手策略如果不算滑点和冲击成本，收益会虚高。

- 把回测收益当承诺： 回测只是历史模拟，不是未来保证。

## 参考项目和资料

- [LEAN](https://www.lean.io/)：QuantConnect 的开源算法交易引擎。

- [Zipline](https://zipline.ml4trading.io/)：事件驱动回测系统。

- [FINRA Algorithmic Trading](https://www.finra.org/rules-guidance/key-topics/algorithmic-trading)：算法交易监管和控制实践。
