# 认知科学与学习方法模块宪章

这个模块服务于整个知识库：不是再增加一堆新知识，而是回答“我怎样真正学会这些知识”。目标是把阅读、理解、记忆、练习、输出和复盘设计成一个闭环。

## 一、模块目标

- 让学习从“看过很多”变成“能说清、能画出、能迁移、能做成”。

- 解释注意力、工作记忆、长期记忆、提取练习、间隔复习和迁移学习的基本机制。

- 把 TIL、概念索引、模块宪章、学习路线、项目练习和搜索系统整合成个人知识库方法。

- 训练复杂判断：基准率、反事实、一阶/二阶影响、系统反馈和认知偏差。

## 二、每篇内容必须落到行动

| 内容类型 | 必须包含 |
| --- | --- |
| 机制解释 | 说明大脑或学习系统发生了什么，避免只给鸡汤。 |
| 方法建议 | 给出可执行步骤，例如如何复习、如何提问、如何做卡片。 |
| 反例提醒 | 说明常见误区，例如只收藏、不提取、不输出、不复盘。 |
| 知识库连接 | 连接到本站已有模块，让方法可以马上用于 Agent、经济、历史、地图和交易学习。 |

## 三、判断是否真的学会

```text
看过：我能指出在哪里读过
说清：我能不用原文复述核心机制
画出：我能画出流程、因果链或结构图
迁移：我能把它用到另一个领域
做成：我能用它完成一个作品、解释一个案例或修正一次判断
```
