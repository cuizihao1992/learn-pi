> Cognitive Learning

# 让你的知识库不只是变大，而是变聪明

你现在的站点已经有 Agent、地图、经济金融、历史社会、量化和科学技术。下一步不是无限堆页面，而是建立一套学习操作系统：如何理解、记忆、检索、迁移、输出，如何避免认知偏差，如何让 AI 成为学习教练。

## 这个模块回答什么

| 问题 | 对应能力 |
| --- | --- |
| 为什么看懂了却记不住？ | 理解工作记忆、长期记忆、提取练习和间隔复习。 |
| 为什么学了很多还是没有体系？ | 用概念、因果链、模块宪章、TIL 和项目练习组织知识。 |
| 为什么判断复杂问题容易偏？ | 识别确认偏误、幸存者偏差、锚定效应、可得性偏差和过度自信。 |
| AI 时代怎么学习更快？ | 把 Agent 当导师、陪练、检索助手、错题本和项目教练。 |

## 一张总图

```text
输入：阅读、视频、对话、代码、案例
  -> 注意力筛选
  -> 工作记忆加工
  -> 形成概念、例子、因果链
  -> 提取练习和间隔复习
  -> 写入知识库：TIL、概念索引、模块页、项目
  -> 输出：讲解、图解、代码、案例分析
  -> 反馈修正：错题、复盘、重构页面
```
