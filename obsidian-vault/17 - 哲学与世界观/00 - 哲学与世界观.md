# 训练追问能力，而不是只收集观点

哲学模块专门处理“第一层问题”：存在、真理、知识、道德、意义、自由、死亡、痛苦和人格尊严。它不替代历史、政治、宗教或科学模块，而是提供一套追问和比较的方法，让你知道一个观点到底在回答什么问题、依赖什么前提、还能被怎样反驳。

## 这个模块解决什么问题

| 问题 | 训练出的能力 |
| --- | --- |
| 为什么一个答案听起来正确，却仍然让人觉得空？ | 区分终极理由、实践路径、情绪共鸣和个人确信。 |
| 不同世界观如何比较？ | 用解释力、自洽性、反驳处理、实践后果和可活性评估观点。 |
| 道德为什么有约束力？ | 理解神圣根基、进化解释、社会契约、功利主义、义务论和德性伦理。 |
| 政治思想能不能回答人生意义？ | 分清终极问题、世界观、治理方案和日常实践的层级。 |

## 核心框架

```text
问题层级
  -> 终极问题：为什么存在？为什么应该？人生为何值得？
  -> 世界观：基督教、佛教、自然主义、康德、存在主义等整体解释
  -> 政治思想：国家、制度、权力、分配、公共秩序
  -> 日常实践：阅读、祷告、修行、工作、服务、行动

分析顺序
  -> 它回答什么问题
  -> 它依赖什么前提
  -> 它解释了什么
  -> 它解释不了什么
  -> 它如何面对最强反驳
  -> 它能不能被真实生活出来
```

## 先记住三个判断

- 一个观点“有用”“流行”“让我舒服”，都不等于它真实。

- 哲学问题不能只靠口号解决，必须追到前提、推理和反驳。

- 真正理解一个世界观，不是能背定义，而是能说明它如何处理存在、道德、痛苦、死亡和行动。
