> History and Society

# 把历史、政治、经济和社会运行放进一张图

你前面问“钱从哪里来、规则谁制定、城市为什么不同、全球规则由谁决定”，这些问题不能只靠经济学回答。还要理解国家能力、制度、战争、技术、地理、身份和国际秩序。这个模块就是为补这块底层框架而建。

## 这个模块解决什么问题

| 问题 | 训练出的能力 |
| --- | --- |
| 为什么一个小事件会引发大规模战争？ | 识别导火索、结构矛盾、联盟锁链、动员机制和误判。 |
| 为什么不同国家的发展路径差异巨大？ | 从地理、制度、国家能力、人口、资本、技术和外部秩序分析。 |
| 全球规则是谁定的？ | 理解大国权力、国际组织、贸易网络、金融体系和安全秩序如何共同作用。 |
| 普通人如何看懂社会新闻？ | 把新闻放进利益、制度、资源、信息和反馈链，而不是只看情绪。 |

## 核心总图

```text
地理与资源
  -> 生产方式与贸易通道
  -> 国家能力、税收能力、军事能力
  -> 制度安排与利益分配
  -> 阶层、身份、民族、意识形态
  -> 国内政治稳定性
  -> 对外战略与国际秩序
  -> 战争、危机、合作、全球化重组
```

## 先记住三个判断

- 历史事件很少只有一个原因，通常是长期结构矛盾遇到短期触发器。

- 国家不是一个单一大脑，内部有政府、军方、资本、民众、地方和精英集团的不同利益。

- 国际体系没有世界政府，规则来自实力、共识、制度、交易和反复博弈。

- 宗教、哲学、政治思想回答的问题层级不同，不能把终极意义和治理方案混为一谈。
