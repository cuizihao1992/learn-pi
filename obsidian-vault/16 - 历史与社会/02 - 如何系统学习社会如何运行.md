# 如何系统学习社会如何运行

如果大学没系统学经济、金融、政治、历史，其实可以后补。关键不是一口气读很多书，而是先建立几条主线：资源如何分配，权力如何组织，规则如何形成，冲突如何升级，技术如何改变社会。

## 五条主线

| 主线 | 核心问题 | 先学什么 |
| --- | --- | --- |
| 经济学 | 资源稀缺时，人和组织如何选择。 | 供需、价格、激励、机会成本、市场失灵。 |
| 金融学 | 跨时间、跨风险的资金如何定价和流动。 | 现金流、利率、折现、风险、信用、杠杆。 |
| 政治学 | 公共权力如何产生、分配、约束和执行。 | 国家能力、合法性、官僚体系、利益集团、制度。 |
| 历史学 | 今天的制度和格局如何一步步形成。 | 工业化、帝国、民族国家、革命、战争、全球化。 |
| 国际关系 | 没有世界政府时，国家如何合作和冲突。 | 权力均势、安全困境、联盟、国际组织、贸易金融秩序。 |

## 八周入门安排

- 第 1 周：读 [[07 - 经济金融/02 - 社会到底是怎么运行的：一张系统总图|社会运行系统]]，把家庭、企业、政府、金融、城市和全球部门放进一张图。

- 第 2 周：读 [[07 - 经济金融/03 - 金钱是怎么流动的，分配规则是谁定的|金钱流动]]，理解工资、房租、税收、政府支出和银行信用。

- 第 3 周：学习国家能力：税收、财政、基础设施、教育、法律、军队和行政组织。

- 第 4 周：学习工业化：能源、机器、工厂、城市化、铁路、金融和全球市场如何互相推动。

- 第 5 周：读 [[16 - 历史与社会/04 - 第一次世界大战的起因：一颗子弹为何引爆整个欧洲|一战起因]]，把权力转移、安全困境和联盟锁链串起来。

- 第 6 周：学习地缘政治：地理位置、资源、交通线、海权、陆权和军事纵深。

- 第 7 周：学习全球化：贸易、汇率、资本流动、跨国公司、美元体系和国际组织。

- 第 8 周：选择一个现实问题，用“结构变量 -> 参与者 -> 反馈链 -> 结果”写一页分析。

## 看新闻时的分析模板

```text
不要先问：谁对谁错？
先问：
1. 资源在哪里？
2. 谁控制规则？
3. 谁承担成本，谁获得收益？
4. 这个制度激励人们做什么？
5. 哪些信息是不透明的？
6. 哪些反馈会放大问题？
7. 有没有外部力量改变局面？
```

## 不要犯的三个错误

- 只用道德好坏解释复杂系统。道德判断重要，但不能替代因果分析。

- 只看一个国家内部，不看全球贸易、资本、能源和安全秩序。

- 只看短期新闻，不看几十年形成的制度、人口、技术和产业结构。
