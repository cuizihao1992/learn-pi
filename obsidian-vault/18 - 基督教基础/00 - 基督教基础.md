# 把圣经、耶稣和福音逻辑讲清楚

基督教模块专门承接“圣经中的人生意义是什么”这条线。它不只是介绍宗教知识，而是系统说明：神、人、罪、耶稣、十字架、复活、信心、祷告和门徒生活如何连成一个整体。

## 这个模块解决什么问题

| 问题 | 训练出的理解 |
| --- | --- |
| 圣经说的人生意义是什么？ | 认识神、荣耀神、爱神爱人、效法基督、与神和好。 |
| 为什么基督教说人有罪？ | 罪不是只做坏事，而是人与神关系断裂、自我中心、离开生命源头。 |
| 为什么耶稣的死和复活是中心？ | 十字架和复活依赖耶稣身份：祂不是普通榜样，而是救赎事件的中心。 |
| 如果还不确定相信，如何开始？ | 从诚实祷告、阅读四福音、提出真实问题开始，而不是先装作已经懂。 |

## 核心链路

```text
创造
  -> 人按神形象被造，有尊严、有关系、有责任
堕落
  -> 罪使人与神、人与人、人与自己、人与世界的关系破裂
救赎
  -> 基督的十字架承担罪的代价，复活显明死亡被胜过
回应
  -> 信心、悔改、祷告、爱神爱人、进入新的生命方向
盼望
  -> 与神和好，并在最终更新中理解死亡、痛苦和未来
```

## 先记住三个判断

- 基督教的人生意义不是先做任务，而是先恢复人与神的关系。

- 十字架不是普通牺牲，复活也不是附加奇迹，它们共同构成福音中心。

- 学习基督教不能只读二手评价，核心问题要回到四福音：耶稣到底是谁。
