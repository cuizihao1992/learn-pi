# 为什么罪、死亡、十字架和复活连在一起

如果只把基督教理解成“劝人做好事”，就很难理解为什么耶稣的死和复活是中心。福音逻辑的关键是：人的问题被理解为人与神关系断裂，而救赎被理解为神在基督里主动恢复这段关系。

## 一、创造：人不是偶然任务机器

基督教认为人按神形象被造，因此人有尊严、有关系能力、有道德责任，也有指向神的目的。人生意义不是先找一个任务填满自己，而是在与神、他人和世界的正确关系中活出来。

## 二、罪：不只是做坏事

| 常见理解 | 基督教更深的理解 |
| --- | --- |
| 罪就是违反规则。 | 罪首先是人与神关系断裂，表现为自我中心、背离神、把受造物当成最终依靠。 |
| 好人没有罪。 | 基督教关注的不只是外在行为，还包括人的心、欲望、动机和生命方向。 |
| 罪只是个人问题。 | 罪也会进入关系、家庭、制度和文化，形成结构性的伤害。 |

## 三、死亡：不只是生物学停止

在基督教里，死亡不只是身体停止运行，也象征人与生命源头隔绝。正因为死亡是深层问题，福音才不是只提供道德建议，而是宣告死亡的权势被胜过。

## 四、十字架：不是普通牺牲

如果耶稣只是普通人，十字架最多是一场悲剧或榜样。但基督教的前提是耶稣的身份决定了十字架的意义：神在基督里主动承担罪的代价，使人与神和好。

```text
罪带来隔绝
  -> 人不能靠自我修补彻底解决
  -> 基督承担罪的代价
  -> 人因信与神和好
  -> 新生命开始改变人的方向
```

## 五、复活：不是附加奇迹

复活不是故事结尾的装饰，而是基督教信仰的中心之一。它至少表达三件事：耶稣身份被显明，死亡没有最终权柄，救赎不是失败而是新创造的开始。

## 六、回应：信心、悔改和祷告

回应福音不是先把自己变成完美的人，而是转向神。信心不是盲目情绪，而是把自己交托给可信的对象；悔改不是自我羞辱，而是承认旧方向错了；祷告不是漂亮话，而是诚实面对神。

```text
如果你真实存在，请引导我认识你。
如果耶稣真是你所差来的，请让我明白。
我不想只是接受一个概念，也不想逃避真实问题。
请帮助我看见真理，也帮助我诚实面对自己。
```
