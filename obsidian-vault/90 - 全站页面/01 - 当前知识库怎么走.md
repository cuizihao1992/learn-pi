# 当前知识库怎么走

## 三、最近应该优先打穿的点

| 模块 | 深挖点 | 原因 |
| --- | --- | --- |
| LLM / Agent | 角色优先级与缓存 | 它连接 API 协议、运行日志、Prompt Cache、KV Cache 和底层硬件缓存。 |
| Mini Agent | OpenAI-compatible 模型接口 | 这是把自研模型接入 Agent 生态的关键工程点。 |
| 经济金融 | 利率如何影响资产价格 | 用一个公式打穿金融定价的入口。 |
| 系统思维 | 反馈环 | 这是跨 Agent、经济、学习、城市系统的通用语言。 |

## 四、每周维护节奏

```text
1. 先选一个模块的一个点，不扩成大而全
2. 写清底层链路、具体例子、常见误解和自测问题
3. 能画图才加图，不能服务理解就不加
4. 有条件就做一个最小实验或交互 demo
5. 更新模块入口、概念索引、学习路线和搜索索引
6. 构建检查、链接检查、提交、推送、验证 Pages
```

## 五、验收问题

- 我能不能用一张图讲清这个模块的核心链路？

- 我能不能举一个具体例子，而不是只背术语？

- 我能不能说出它和相邻模块的边界？

- 我能不能指出这个系统最容易失败在哪里？

- 我能不能做一个最小 demo 或项目来验证它？
