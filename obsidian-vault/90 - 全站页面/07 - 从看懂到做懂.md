# 从看懂到做懂

实验室不是另一个内容目录，而是验证理解的地方。每个实验都把一个抽象概念变成可输入、可观察、可调参的小系统。

## 实验路线

```text
读概念
  -> 看链路
  -> 做实验
  -> 观察失败模式
  -> 回到模块复盘
  -> 沉淀成项目能力
```

## 当前实验

### Embedding Search Demo

输入一个问题，观察它如何被映射成教学向量，再按相似度召回最相关知识片段。适合理解 embedding、语义搜索和 RAG 的第一步。
[打开实验](examples/embedding-search/index.html)

### Embedding -> RAG 深挖

把 demo 背后的底层原理讲透：向量、余弦相似度、chunk、topK、rerank 和失败模式。
[[03 - LLM 与 Agent/03 - 为什么 RAG 的第一步是 embedding 召回|阅读深挖]]

### Mini RAG Demo

从文档切片、教学向量、topK 召回、prompt 拼接到带引用回答，观察一次完整 RAG 闭环。
[打开实验](examples/mini-rag/index.html)

### RAG Evaluation Demo

用标准问题、期望证据和答案要点，观察 Recall@K、MRR、忠实度和完整度如何定位问题。
[打开实验](examples/rag-evaluation/index.html)

### Mini Agent Loop 深挖

### Agent Evaluation Demo

## 实验标准

- 每个实验只验证一个核心概念。

- 必须能输入不同案例，观察结果变化。

- 必须写清楚它是教学模型，不等于生产系统。

- 必须反向链接到对应课程页面。
