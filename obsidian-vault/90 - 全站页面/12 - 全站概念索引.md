# 全站概念索引

当你被术语卡住时，不要硬读。先找到它属于哪条链路、连接哪些概念、应该回到哪个模块。这个页面不是词典，而是全站的概念路由器。

## 概念如何流动

```text
TIL 学习日志

  -> 概念索引建立连接
  -> 模块页面展开解释
  -> 案例和 demo 验证理解
  -> 搜索索引帮助找回
```

## Agent 与大模型

| 概念 | 一句话 | 入口 |
| --- | --- | --- |
| toolCall | 模型提出“我要调用哪个工具和参数”。 | 工具调用 |
| toolResult | 运行时执行工具后，把真实结果回填给模型。 | Mini Agent |
| OpenAI-compatible | 让不同模型伪装成同一种 API 协议。 | 模型接口 |
| Embedding | 把文本、图片、代码等对象变成可比较的语义向量。 | Embedding 与多模态 |
| RAG | 先检索证据，再让模型回答。 | RAG 工程 |
| 多模态模型 | 把图像、音频、视频等模态接入语言模型的理解和生成能力。 | Embedding 与多模态 |
| Prompt Cache | 复用稳定 prompt 前缀的预填充计算，减少重复推理成本。 | 角色优先级与缓存 |
| KV Cache | 推理时保存历史 token 的 Key/Value，避免每生成一个 token 都重算历史上下文。 | 角色优先级与缓存 |
| 运行日志 | Agent 本轮可见的 system、developer、user、assistant、tool、RAG 证据和文件片段。 | 角色优先级与缓存 |
| 自回归生成 | 用已经生成的前文预测下一个 token，因此 token 与 token 之间天然串行。 | 投机解码原理 |
| Speculative Decoding | 小模型先草拟多个 token，大模型一次验证并接受最长有效前缀。 | 投机解码原理 |
| DFlash | 用轻量 block diffusion / masked parallel prediction drafter 一次生成一块草稿 token。 | 投机解码原理 |
| TileRT | 面向低延迟推理的 runtime，通过 persistent kernel、tile pipeline 等减少 GPU 执行缝隙。 | MiMo UltraSpeed 案例 |
| GPU 调度碎片 | kernel 启动、同步、通信和数据搬运之间的微小等待，会在高速推理中放大成瓶颈。 | MiMo UltraSpeed 案例 |
