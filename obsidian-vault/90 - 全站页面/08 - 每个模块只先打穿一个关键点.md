> Deep Dive Roadmap

# 每个模块只先打穿一个关键点

这个计划不是把模块做大而全，而是为每个模块选一个最能代表底层原理的点，用一句话模型、底层链路、具体例子、最小实验、常见误解和自测题讲透。

## 深挖模板

```text
一个关键点
  -> 一句话模型
  -> 需要补的前置知识
  -> 底层链路图
  -> 具体例子
  -> 最小实验 / 可观察 demo
  -> 常见误解
  -> 自测问题
  -> 回到模块复盘
```

## 推进顺序

- 第一批：Embedding -> RAG、Mini RAG Demo、RAG Evaluation、Mini Agent Loop、Agent Evaluation、Agent Safety、Pi toolCall 闭环。

- 第二批：利率折现、K 线指标数学、Layer / Source / Style。

- 第三批：DrawCommand、Gaussian Splatting、数字孪生实时状态。

- 第四批：回测陷阱、核电池能量转换。

- 结构优化批次：统一模块首页，再拆分 Mini Agent 这类过长教程型首页。

## 完成标准

| 层级 | 标准 |
| --- | --- |
| 讲清 | 能用一句话说出这个点解决什么问题。 |
| 画出 | 能画出输入、核心机制、输出和失败点。 |
| 举例 | 能用一个具体例子解释它为什么有用。 |
| 实验 | 能通过一个最小 demo 观察结果变化。 |
| 自测 | 能回答常见误解和边界条件。 |
