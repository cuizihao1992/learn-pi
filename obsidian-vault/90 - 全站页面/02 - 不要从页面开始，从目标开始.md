> Learning Paths

# 不要从页面开始，从目标开始

这个网站已经有 18 个模块。小白最容易卡住的地方不是资料不够，而是不知道先学哪条线。这里把内容按目标重组：想开发 Agent、准备面试、理解大模型推理加速、学地图渲染、做数字孪生、理解经济金融与社会系统、研究哲学信仰，或者建立自己的学习系统，可以直接选路线。

## 先选一个目标

| 我想要 | 推荐路线 | 最终能力 |
| --- | --- | --- |
| 自己开发 Agent | Agent 产品实战路线 | 能写一个带工具、模型适配、记忆、RAG、前端事件流的最小产品。 |
| 准备大模型 / Agent 面试 | LLM 面试路线 | 能讲清记忆机制、RAG、长上下文、Transformer 长文本优化。 |
| 理解大模型为什么能更快 | 大模型推理加速路线 | 能讲清自回归瓶颈、投机解码、DFlash、FP4、MoE、TileRT 和 GPU 调度碎片。 |
| 理解地图和三维渲染 | GIS / 渲染路线 | 能区分 OpenLayers、Mapbox、Cesium 的架构和适用场景。 |
| 做城市级可视化系统 | 数字孪生路线 | 能设计地图底座、三维资产、实时数据、Agent 分析和 MVP。 |
| 理解社会运行 | 经济金融与社会系统路线 | 能从社会运行、金钱流动、财政货币、城市经济、全球化走到金融和量化。 |
| 理解人生意义和信仰 | 哲学、世界观与基督教路线 | 能区分终极问题、世界观、政治思想和日常实践，并讲清基督教福音核心逻辑。 |
| 扩展科学技术视野 | 科学技术路线 | 能理解高斯分布、高斯泼溅、核电池和卫星原子钟的关键概念。 |

## 路线一：Agent 产品实战

适合目标：想从小白走到“能开发自己的 Agent”。

- [[01 - Pi Agent/00 - Pi Agent|Pi Agent 总览]]：先看真实 Agent 工程有哪些层。

- [[01 - Pi Agent/02 - 完整例子：从一句话到模型、工具、前端|Pi 完整运行流程]]：理解 prompt、model、toolCall、toolResult、final answer 的闭环。

- [[02 - Mini Agent/00 - Mini Agent|Mini Agent MVP]]：用 Node 写出最小 Agent Loop。

- [[02 - Mini Agent/02 - 最小 Agent Loop：模型决策、工具执行、结果回填|最小 Agent Loop 深挖]]：把模型决策、工具执行、结果回填和终止条件拆成一个闭环。

- [Agent Evaluation Demo](examples/agent-evaluation/index.html)：用 trace 判断工具选择、参数、toolResult grounding 和最终回答。

- [Agent Safety Demo](examples/agent-safety/index.html)：理解路径边界、命令白名单、写文件确认和密钥外传拦截。

- [[02 - Mini Agent/03 - 如何让自己训练的模型被 Agent 使用|模型接口兼容]]：理解 OpenAI-compatible、自研模型中间层、Anthropic 差异。

- [[02 - Mini Agent/04 - 从零开发自己的 Agent：一条能动手的路线|从零实战路线]]：把命令行 Agent 做成带前端、记忆和 RAG 的小产品。

- [[03 - LLM 与 Agent/01 - 长期陪伴型 AI 角色的记忆机制怎么设计|AI 记忆机制]]：给 Agent 加短期记忆、用户画像和长期情景记忆。

- [[03 - LLM 与 Agent/04 - RAG 向量数据全流程工程化方案|RAG 数据工程]]：给 Agent 接知识库。

```text
验收标准：
用户在网页输入任务
  -> Agent 能选择工具
  -> 工具结果回填给模型
  -> 前端能看到工具调用过程
  -> Agent 能记住项目偏好
  -> Agent 能从本地文档检索答案
```

## 路线二：LLM / Agent 系统课

适合目标：面试算法岗、Agent 应用岗、RAG 工程岗、大模型系统岗。不要先背名词，先用一个具体问题打穿“语义表示 -> 证据召回 -> prompt 生成 -> 评估”的闭环。

- [[03 - LLM 与 Agent/00 - LLM 与 Agent|课程入口]]：先建立 LLM / Agent 系统链路。

- [[03 - LLM 与 Agent/03 - 为什么 RAG 的第一步是 embedding 召回|Embedding -> RAG 深挖]]：用具体例子理解一句话如何找到正确证据。

- [Mini RAG Demo](examples/mini-rag/index.html)：观察文档切片、topK 召回、prompt 拼接和引用回答。

- [RAG Evaluation Demo](examples/rag-evaluation/index.html)：用 Recall@K、MRR 和忠实度判断系统错在哪里。

- [[03 - LLM 与 Agent/04 - RAG 向量数据全流程工程化方案|RAG 向量数据工程]]：数据清洗、语义切片、向量库、混合检索、rerank、评估。

- [[03 - LLM 与 Agent/01 - 长期陪伴型 AI 角色的记忆机制怎么设计|长期陪伴 AI 记忆机制]]：分层存储、异步更新、冲突和遗忘。

- [[03 - LLM 与 Agent/05 - 长上下文模型会取代 RAG 吗|长上下文 vs RAG]]：讲清二者互补关系和 Long RAG。

- [[03 - LLM 与 Agent/06 - Transformer 处理超长上下文的瓶颈与优化方案|Transformer 长文本优化]]：O(n^2)、KV Cache、FlashAttention、GQA、PagedAttention、RoPE/ALiBi。

- [[03 - LLM 与 Agent/07 - 角色优先级、运行日志和缓存到底是什么关系|角色优先级与缓存]]：讲清 system/developer/user/tool 的优先级、运行日志、Prompt Cache 和 KV Cache。

- [[03 - LLM 与 Agent/08 - 大模型 Agent 算法面试怎么答|答题模板]]：把知识组织成两分钟答案。

```text
答题骨架：
先给结论
  -> 画系统链路
  -> 讲工程取舍
  -> 讲失败模式
  -> 讲评估指标
  -> 落到真实系统怎么做
```

## 路线三：大模型推理加速

适合目标：想理解为什么某些大模型能宣称 1000 tokens/s，普通自回归模型慢在哪里，以及算法和 GPU runtime 如何配合。

- [[04 - LLM 推理加速/00 - LLM 推理加速|大模型推理加速总览]]：先建立普通生成、投机解码和 runtime 优化的总图。

- [[04 - LLM 推理加速/02 - 预测一个 token 和验收多个 token，不是一回事|投机解码原理]]：理解 drafter、verifier、接受率和最长有效前缀。

- [[04 - LLM 推理加速/03 - MiMo-V2.5-Pro-UltraSpeed 为什么快|MiMo UltraSpeed 案例]]：拆解 DFlash、FP4、MoE、TileRT 为什么能共同提速。

- [[03 - LLM 与 Agent/07 - 角色优先级、运行日志和缓存到底是什么关系|角色优先级与缓存]]：补 KV Cache、Prompt Cache、GPU cache 等推理基础。

## 路线四：GIS / 渲染

适合目标：想理解地图、WebGL、三维引擎、渲染命令如何到 GPU。

- [[13 - OpenLayers/00 - OpenLayers|OpenLayers 总览]]：先学传统二维 GIS 的 Map、View、Layer、Source。

- [[13 - OpenLayers/01 - OpenLayers 完整渲染路径：从 Map 到 Canvas WebGL|OpenLayers 渲染路径]]：看瓦片、矢量、Canvas/WebGL 如何画出来。

- [[11 - Mapbox/00 - Mapbox|Mapbox 总览]]：理解 source、layer、style、vector tiles。

- [[11 - Mapbox/02 - Mapbox 和 Cesium 对比：为什么 Mapbox 常常感觉性能更好|Mapbox 与 Cesium 对比]]：理解为什么 Mapbox 在二维场景通常更轻快。

- [[12 - Cesium/00 - Cesium|Cesium 总览]]：进入三维地球和大规模 3D Tiles。

- [[12 - Cesium/01 - Cesium 完整渲染路径：从 Viewer 到 GPU|Cesium 完整渲染路径]]：从 Viewer、Scene、Primitive 到 DrawCommand。

- [[12 - Cesium/02 - Cesium 如何写自定义着色器：从 API 到 DrawCommand|Cesium 自定义着色器]]：理解 shader 最终如何进入渲染命令。

## 路线六：经济金融与社会系统

适合目标：想理解钱如何流动、工资房租如何形成、政府和市场如何共同分配，再入门金融市场和量化交易系统。

- [[07 - 经济金融/00 - 经济金融|经济学与金融学总览]]：先建立价格、资源、现金流、利率和风险框架。

- [[07 - 经济金融/02 - 社会到底是怎么运行的：一张系统总图|社会运行总图]]：把家庭、企业、政府、金融、城市和全球部门放进一张系统图。

- [[07 - 经济金融/03 - 金钱是怎么流动的，分配规则是谁定的|金钱流动与分配]]：理解工资、房租、物价、税收、政府支出、银行信贷和全球规则。

- [[07 - 经济金融/04 - 政府的钱、银行的钱、老百姓的钱怎么连起来|财政与货币循环]]：理解税收、国债、央行、银行贷款和信用创造。

- [[07 - 经济金融/05 - 为什么一线城市工资高，房租也高，什么都贵|城市经济]]：理解一线城市和小地方的工资、房租、物价和机会差异。

- [[07 - 经济金融/06 - 全球化以后，钱和规则怎么流动|全球化规则]]：理解贸易、汇率、美元体系、资本流动和国际组织。

- [[07 - 经济金融/07 - 经济学：研究稀缺资源如何配置|经济学基础框架]]：理解稀缺、机会成本、供需、弹性、市场失灵。

- [[07 - 经济金融/09 - 金融学：研究资金如何跨时间和风险配置|金融学基础框架]]：理解现金流、时间价值、折现率、风险收益。

- [[07 - 经济金融/10 - 利率如何通过折现影响资产价格|利率折现深挖]]：用最小数学例子理解加息为什么压估值。

- [[07 - 经济金融/11 - 宏观指标与经济周期怎么读|宏观指标与周期]]：理解 GDP、通胀、就业、利率、信用和资产价格。

- [[08 - 股票 K 线/00 - 股票 K 线|股票 K 线总览]]：再建立价格、成交量、趋势、风控框架。

- [[08 - 股票 K 线/02 - K 线到底在表达什么|K 线基础]]：理解单根 K 线和组合形态。

- [[08 - 股票 K 线/03 - 常见指标的底层逻辑：它们到底在算什么|指标底层逻辑]]：理解均线、MACD、RSI、KDJ、布林带到底在加工什么。

- [K 线指标 Demo](examples/kline-indicators/index.html)：输入价格序列，观察 SMA、EMA、MACD、RSI 的计算过程。

- [[08 - 股票 K 线/04 - 买入卖出信号：不要背口诀，要拆条件|买卖信号整理]]：按长短线组织信号，而不是孤立看指标。

- [[08 - 股票 K 线/07 - 风控和交易日志：看懂图只是开始|风控日志]]：学会仓位、止损、复盘。

- [[09 - 量化交易/00 - 量化交易|量化交易总览]]：从人工判断走到策略系统。

- [[09 - 量化交易/01 - 一个量化交易系统通常长什么样|量化系统架构]]：理解数据、研究、回测、实盘、风控、监控。
